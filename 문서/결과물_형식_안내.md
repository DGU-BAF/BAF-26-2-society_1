# 결과물 형식 안내

노트북(`코드/안심구역_분석노트북.ipynb`)을 끝까지 실행하면 노트북과 같은 폴더(`코드/`)에 `결과` 폴더가 만들어지고 아래 형태로 저장됩니다(위치는 셀 1 의 `OUT_DIR` 로 바꿀 수 있음).
`결과/00_결과물_목록.csv`에 파일 전체 목록(단위·내용)이 함께 저장됩니다.

## 1. 폴더 구조

```
결과/
├─ 00_결과물_목록.csv           ← 모든 결과 파일의 단위·내용 목록 (반출 심사 제출용)
├─ 반출후보/                    ← 집계 표(전국·시도·시군구·집단 단위). 반출 신청 대상
│   ├─ 00_실행요약.json         ← 핵심 수치·설정 한 장 요약
│   ├─ 01~12_*.csv              ← 아래 2번 표 참고
│   └─ README_반출전_확인.txt
├─ 내부용/                      ← 행정동 단위 표. 분석·검토용(반출 비권장)
└─ 그림/                        ← PNG 4장 (로렌츠, 충전 도달 곡선, 4분면 산점도, 월별 추세)
```

- 모든 CSV는 **UTF-8(BOM)** 이라 엑셀·주피터에서 한글이 깨지지 않습니다.
- 건수가 `MIN_CELL`(기본 5) 미만인 칸은 `<5` 처럼 가려집니다(반출후보 폴더의 표만). 반출 규정의 기준값에 맞춰 셀 1의 `MIN_CELL`을 조정하세요.

## 5. 결과를 읽을 때 꼭 알아둘 것

- 공백 정의가 두 가지입니다. **엄격(strict)** = 행정동 경계 안에 영업 주유소가 0개이면서 중심점 거리 초과(하한), **중심점(centroid)** = 중심점 거리만 초과(상한). 진짜 값은 둘 사이이므로 **두 값을 함께 보고**하세요.
- 기준값(5km, 충전 실사용 25분위, 연속 3개월 등)은 모두 임의입니다. `12_민감도_요약.csv`로 결론이 유지되는지 확인하세요.
- 사건(충전 시작) 수가 10건 안팎이면 Cox 같은 다변량 결과는 참고용입니다. Kaplan-Meier·log-rank·사례 중심으로 해석하세요.
- `관측이전부터_공백(left_truncated)` 시차는 하한값입니다(실제 공백은 그 이전부터).
- 매칭 결과는 사례 선정이며 인과 효과가 아닙니다.
- 한전 자료에 행이 없는 행정동은 충전 0으로 간주합니다(품질점검에서 비율 확인).
