# 안심구역 반입 패키지 — 사용 설명서

한국전력공사 EV 충전전력량(사업자/비사업자)과 주유소 접근성 데이터를 결합해 **기름도 전기도 쓰기 어려운 동네(이중공백)** 를 진단하는 분석 패키지입니다.

## 1. 패키지 구성

```
안심구역_반입패키지/
├─ 코드/안심구역_분석노트북.ipynb      ← 주피터 노트북 (파이썬 3, pandas·numpy 만 필수)
├─ 데이터/                            ← 반입하는 외부데이터 (모두 공공데이터 가공본, 개인정보 없음)
│   ├─ 행정동_마스터.csv               3,558개 행정동: 인구·65세 이상·면적·충전기 개소수·인구감소지역 등
│   ├─ 행정동_월별_최근접주유소거리.csv  행정동×월(2018-01~2026-09) 최근접 영업 주유소 거리(km)
│   ├─ 행정동_월별_경계안주유소수.csv    행정동×월 경계 안 영업 주유소 수
│   ├─ 시군구_마스터.csv               251개 분석 단위: 인구·고령비율·증감률·인구밀도
│   ├─ 외부데이터_병합_법정동기준_반입용.csv  법정동↔행정동 연결 + 외부데이터 (한전 법정동 연결용)
│   └─ 법정동_행정동_연계표_최신(2025-04-01).csv  국가데이터처 연계표 (지역 이름→코드 연결 보조)
└─ 문서/                              ← 이 설명서, 결과물 형식 안내
```

## 2. 안심구역에서 실행하는 순서

1. 패키지를 한 폴더에 풀고(`코드`, `데이터` 폴더 구조 유지) `코드/안심구역_분석노트북.ipynb` 를 주피터로 엽니다.
2. **셀 1** 의 `PATH_KEPCO` 만 한전 파일 경로로 고칩니다.
   ```python
   PATH_KEPCO = {"비사업자": r"D:\한전\비사업자.csv", "사업자": r"D:\한전\사업자.csv"}
   ```
   - 윈도우 경로는 반드시 앞에 `r` 을 붙이세요(`r"..."`). 안 붙이면 `unicodeescape` 에러가 납니다.
   - 파일이 여러 개(연도별 등)면 와일드카드를 쓰세요: `r"D:\한전\비사업자_*.csv"`
3. **위에서부터 셀을 순서대로 실행**합니다 (Kernel → Restart & Run All 도 가능).
4. 먼저 확인할 두 곳:
   - **셀 3**: 한전 컬럼 자동 추정(날짜·시도·시군구·읍면동·시간대 24개)이 맞는지
   - **셀 6**: `지역 연결 결과 … kWh 가중 연결률 %` (90% 이상이면 정상) 와 `미연결 상위 20`
5. 마지막 셀의 **자체 점검** 문구를 확인하고 `결과` 폴더를 열어봅니다. `결과` 폴더는 **노트북이 있는 폴더(코드/) 안에** 만들어집니다(`문서/결과물_형식_안내.md` 참고). 같은 폴더를 엑셀 등으로 열어 둔 채 다시 실행하면 저장 오류가 나므로 닫고 실행하세요.
6. 반출할 파일은 `결과/반출후보/` 에서 고르고, 규정에 맞게 셀 1 의 `MIN_CELL` 을 조정해 다시 실행합니다.

## 2-1. 실행 환경

- 파이썬 3.7 이상, **pandas 0.25 이상 + numpy** 만 있으면 됩니다(파이썬 3.8 + pandas 1.3.5 + numpy 1.21 환경에서 matplotlib·statsmodels·openpyxl 없이 전체 실행 시험 완료).
- 선택 라이브러리: matplotlib(그림), statsmodels(Cox), openpyxl(엑셀 입력). 없으면 해당 부분만 자동 생략되고 나머지는 정상 실행됩니다.
- 한전 파일이 엑셀(.xlsx)인데 openpyxl 이 없으면 안내 문구와 함께 멈춥니다 → CSV 로 내보내서 쓰세요.
- 노트북은 코드 셀을 위에서부터 한 번씩 순서대로 실행하는 것을 전제로 합니다. 중간 셀에서 멈췄다면 원인을 고치고 **Kernel → Restart & Run All** 로 처음부터 다시 실행하세요.

## 3. 한전 데이터 구조 — 자동 처리하는 경우

기본 가정: **날짜, 시도, 시군구, 읍면동, 고객호수, 1:00~24:00(24개 시간대)**, 사업자·비사업자 두 파일. 일별 자료가 **날짜순으로 정렬**(하루치 전 지역이 먼저, 그다음 날)돼 있어도, 지역순으로 정렬돼 있어도 결과가 같습니다(청크 단위 집계 후 합산, 입력 kWh = 월집계 kWh 로 시험). 아래 변형도 자동 처리합니다(모두 시험 완료).

| 구분 | 자동 처리 |
|---|---|
| 파일 | CSV/TXT/XLSX, 인코딩(UTF-8·UTF-8-BOM·CP949·UTF-16), 구분자(쉼표·탭·세미콜론·파이프), 제목행이 앞에 있는 파일, 연도별 여러 파일(와일드카드), 큰 파일(청크) |
| 날짜 | `2023-01-15`, `20230115`, `2023.01.15`, `202301`, 날짜시간, 엑셀 일련번호, 연도·월 따로 |
| 시간대 | `1:00~24:00`, `01:00~24:00`, `0:00~23:00`, `01시~24시`, `H1` 등 (24개) |
| 지역 | 이름(법정동명·행정동명·리 단위 포함), 시도 약칭·옛이름(강원도·전라북도), 시군구 일반구 포함/제외, 전남광주통합특별시, 군위군 대구 편입, 코드(법정동 10·8자리, 행정동, 시도·시군구·읍면동 코드 3분할), 이름+코드 |
| 값 | 천단위 쉼표, 마스킹 기호(`*`, `-`), 합계·소계 행, Wh/MWh 단위(`UNIT_FACTOR`), 고객호수 없음, 시도 컬럼 없음 |

가정이 틀리면 셀 1 의 `OVERRIDE` 에 컬럼명을 직접 지정합니다(예: `OVERRIDE["emd_col"] = "읍면동명"`).

## 4. 자주 나는 문제와 해결

| 증상 | 원인 / 해결 |
|---|---|
| `unicodeescape` 에러 | 윈도우 경로 앞에 `r` 을 붙이세요 |
| `FileNotFoundError` (데이터 파일) | `데이터` 폴더가 노트북 폴더 옆(또는 같은 폴더)에 있어야 합니다. 셀 1 의 `DATA_DIR` 확인 |
| 셀 3 에서 `…컬럼을 못 찾음` | `OVERRIDE` 로 해당 컬럼을 직접 지정 |
| 셀 6 연결률 90% 미만 | `미연결 상위 20` 을 보고 표기 차이 확인. 같은 시군구 안에서 읍면동(리) 이름이 겹치면 일부러 연결하지 않습니다 |
| 메모리 부족 | 셀 1 의 `CHUNK` 를 줄이세요(예: 100000) |
| `MemoryError`/매우 느림 | 한전 파일을 연도별로 나눠 와일드카드로 지정 |
| 그림이 안 나옴 | matplotlib 이 없으면 자동 생략됩니다(표는 모두 저장) |
| Cox 결과 없음 | statsmodels 가 없으면 자동 생략(Kaplan-Meier·log-rank 는 있음) |

## 6. 알아둘 가정과 한계

- **주유소 공백의 두 정의**: 중심점 기준은 면적이 넓은 읍면에서 거리가 과대하게 나올 수 있어(상한), 경계 안 주유소 0개를 더한 엄격 기준(하한)과 함께 봅니다. 도로망 거리·집계구 단위 인구는 반영하지 않았습니다.
- **충전기 개소수**는 환경공단 설치현황(2021·현재 2시점)이라 가동률은 근사치입니다.
- **야간 시간대**는 23시~다음날 9시로 가정했습니다(셀 1 `NIGHT_IDX`, 한전 정의 확인 후 수정).
- 시간대 `1:00` 은 '0~1시'로 봅니다(`HOUR_LABEL_END`).
- 기준값(5km, 충전 25분위, 연속 3개월, 유형 규칙)은 임의이며 민감도 표로 확인합니다.
- 한전 자료 행이 없는 행정동은 충전 0으로 간주합니다.
- 인구는 현재 시점 하나이므로 과거 월의 1천명당 kWh 는 근사입니다.
